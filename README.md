# smart job portal (mern)
A full-stack Job Portal application where **candidates can apply for jobs** and **recruiters can manage applicants**, built using the MERN stack with role-based authentication and a modern dark UI.

---

## 🚀 Features

### 👤 Candidate
- User authentication (JWT)
- View available jobs
- Apply to jobs with **PDF resume upload**
- Secure access with protected routes

### 🧑‍💼 Recruiter
- Recruiter authentication
- Post jobs
- View applicants for posted jobs
- Download candidate resumes

### 🔐 Security & Architecture
- JWT-based authentication
- Role-based authorization (Candidate / Recruiter)
- Protected frontend routes
- Secure file uploads using Multer
- MVC architecture on backend

### 🎨 UI
- Custom **Dark Mode UI**
- Built with **Tailwind CSS**
- Responsive layout
- Clean and modern design

---

## 🛠 Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT (jsonwebtoken)
- bcryptjs
- Multer (resume upload)
